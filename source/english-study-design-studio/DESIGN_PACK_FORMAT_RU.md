# Формат дизайнерского набора ESDS (0.9.0)

## Как использовать

1. В Obsidian открой English Study Design Studio → «Библиотека».
2. В разделе «Полные дизайнерские наборы» нажми «Импорт дизайнерского набора».
3. Выбери файл с расширением `.esds-theme.json` или `.json`.
4. Плагин добавит палитру, фон и стиль блоков в соответствующие разделы, автоматически свяжет их и выберет новый набор.
5. Нажми «Предпросмотр» и затем «Применить к заметке», когда будешь готов. Сам импорт не меняет заметки.

Для переноса текущего сочетания используй «Экспорт текущего набора». Файл сохраняется в папку хранилища `ESDS Exports`.

Отдельные палитры, фоны и стили блоков по-прежнему импортируются и экспортируются через отдельные кнопки.

## Структура файла

```json
{
  "schemaVersion": 1,
  "type": "esds-theme-pack",
  "plugin": "english-study-design-studio",
  "name": "Название набора",
  "items": {
    "palette": { "...": "поля палитры ESDS" },
    "background": { "...": "поля фона ESDS" },
    "blockStyle": { "...": "поля стиля блоков ESDS" }
  }
}
```

Точный пример заполнения находится в `templates/theme-pack-template.json`.

## Поддерживаемые параметры рамок

`blockStyle.framePreset` принимает одно из значений: `classic`, `dashed`, `dotted`, `double`, `left`, `none`, `top`.

`blockStyle.frameOverrides` — необязательный объект переопределений по типам callout, например `{ "warning": "left", "important": "double" }`. Допустимые ключи типов совпадают с существующими типами блоков ESDS.

Импорт проверяет цветовые роли, фоновые CSS-значения, структуру и версию пакета. Файл не может выполнить произвольный JavaScript. Внешние изображения и URL-фоны не поддерживаются.


### Цвета отдельных блоков в палитре (0.8.2)

Палитра может содержать необязательные карты цветов для каждого Callout:

- `calloutFills` и `darkCalloutFills` — заливка;
- `calloutTexts` и `darkCalloutTexts` — цвет текста всего блока (заголовок и содержимое);
- `calloutBorders` и `darkCalloutBorders` — цвет обводки.

В каждой карте ключами служат типы Callout (`rule`, `example`, `important`, `tip`, `warning`, `question`, `practice`, `success`, `info`, `note`, `quote`, `abstract`). Значение допускает HEX (`#RRGGBB`) или RGB-массив `[r,g,b]`. Если для типа/режима значение не задано, используется соответствующий цвет из `callouts` / `darkCallouts`. Стили блоков определяют геометрию рамок и не переопределяют цвета палитры.

Начиная с ESDS 0.9.16 параметр `defaultBlocks` автоматически выбирает внутренний базовый профиль плотности и отступов для блоков этой палитры. Пользователю не нужно отдельно выбирать стиль блоков: основная палитра уже включает готовое оформление. Цвета и тематическая геометрия каждого Callout задаются самой палитрой через `callouts`, карты `calloutFills`/`calloutTexts`/`calloutBorders` и `calloutFrames`. При выборе новой палитры её `defaultBlocks` применяется автоматически, поэтому настройки предыдущей палитры не должны протекать в новую. Старые самостоятельные стили блоков сохраняются для совместимости и дополнительных ручных настроек.


### Тематические рамки палитры (0.9.0)

Палитра schemaVersion 3 может содержать `calloutFrames`. Для каждого Callout задаются `preset`, `width` и `radius`. Допустимые preset: `classic`, `dashed`, `dotted`, `double`, `left`, `none`, `top`. Если для типа нет отдельной записи, в режиме рамок палитры используется безопасная классическая рамка.

В обычном сценарии источник геометрии автоматически установлен в `palette`: активная палитра предоставляет собственные `calloutFrames`. Дополнительный редактор локального оформления может временно переопределять геометрию только для конкретной заметки. Цвета Callout всегда берутся из активной палитры, если пользователь явно не задал локальное переопределение.

Полный дизайнерский набор дополнительно сохраняет `frameSource` (`palette` или `blockStyle`), чтобы переносить выбранную модель оформления. Старые наборы без этого поля импортируются в режиме `blockStyle`.
