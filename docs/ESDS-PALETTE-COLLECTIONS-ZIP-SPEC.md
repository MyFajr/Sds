# ESDS — Техническое задание: управление коллекциями палитр и ZIP-импорт/экспорт

## Цель
Сделать добавление и управление коллекциями палитр быстрым и безопасным. ZIP-коллекция добавляется в общую библиотеку ESDS без замены пользовательских данных.

## 1. ZIP-импорт коллекции палитр
- Доступен из библиотеки оформления и из просмотра категории палитр.
- При запуске из категории текущая категория предлагается как назначение по умолчанию.
- Пользователь может выбрать существующую категорию или создать новую.
- При создании новой категории имя автоматически берётся из имени ZIP-файла без расширения .zip; не требовать ручного ввода.
- Поддерживать ZIP, содержащий отдельные JSON-файлы палитр; обходить папки внутри архива.
- Не импортировать README, изображения, data.json и JSON, не являющиеся палитрами ESDS.
- Проверять схему, версию формата и обязательные цветовые роли перед изменением библиотеки.
- Сформировать предварительный итог: найдено, валидно, дубликаты, некорректные файлы.
- Добавлять все валидные уникальные палитры одной операцией сохранения.
- Не заменять и не удалять существующие палитры автоматически.
- Отчёт после импорта: добавлено/пропущено/ошибок, с именами файлов и причинами.
- При отмене или ошибке чтения архива библиотека не меняется.
- После импорта открыть выбранную категорию и обновить список.

## 2. Дубликаты
- Сопоставлять прежде всего стабильный palette ID, затем нормализованное имя в пределах библиотеки.
- Дубликаты по умолчанию пропускать.
- Не перезаписывать существующую палитру молча.
- В будущем предусмотреть отдельный явный режим «заменить», с просмотром различий и подтверждением.

## 3. Экспорт ZIP
- Экспортировать выбранную категорию целиком в ZIP.
- Сохранять каждый элемент как самостоятельный JSON в папке категории внутри архива (или в корне архива с безопасными именами).
- Имя ZIP по умолчанию — название категории.
- Включать manifest коллекции с названием, датой экспорта и количеством палитр.
- Экспорт не изменяет библиотеку.

## 4. Менеджер категорий
- Создание, переименование, удаление, изменение порядка.
- Удаление категории должно требовать выбора: перенести её палитры в другую категорию, удалить палитры или отменить.
- Объединение категорий: перенос всех элементов в выбранную категорию с подтверждением.
- Переименование/объединение должно обновлять категории у всех элементов и метаданные категории.
- Не удалять системные категории без явного решения; защищённые категории нельзя удалять.
- Сохранять порядок и метаданные после перезапуска.

## 5. Управление палитрами
- Перемещение одной палитры в другую категорию из меню карточки.
- Массовый выбор палитр: переместить или удалить несколько.
- Дублирование палитры с новым уникальным ID и понятным названием.
- Удаление палитры с подтверждением; удалить из избранного/связанных ссылок при необходимости.
- Поиск по названию, описанию и категории.

## 6. Единый подход к библиотеке ESDS
В перспективе аналогичные безопасные операции должны быть доступны для фонов и стилей блоков: импорт/экспорт, перемещение по категориям, дублирование, удаление. Полное восстановление библиотеки остаётся отдельной операцией, явно предупреждающей о замене текущих данных.

## 7. UX и доступность
- Кнопки и диалоги должны работать на Android и desktop.
- Не использовать сложные ручные шаги, если можно вывести значение из контекста.
- Явные состояния загрузки/обработки и ошибки.
- Сохранять текущую категорию и возвращать пользователя к ней после операции.
- Не требовать стороннего платного сервиса.

## 8. Проверки и критерии приёмки
- ZIP с несколькими валидными JSON импортируется за один раз.
- Импорт в существующую категорию назначает все новые палитры туда.
- Импорт в новую категорию создаёт её автоматически из имени ZIP без расширения.
- Повторный импорт не создаёт дубликатов и не меняет существующие элементы.
- Повреждённый ZIP или полностью некорректная коллекция не изменяет библиотеку.
- Частично валидный ZIP добавляет валидные элементы и показывает подробный отчёт.
- Экспорт категории можно импортировать обратно без потери палитр.
- Переименование, объединение и удаление категории не оставляют палитры с потерянной категорией.
- Существующие функции импорта одиночного JSON и полного восстановления библиотеки продолжают работать.
