# Техническое задание ESDS 0.9.18 — завершение универсальной инструкции и реестра

**База:** подтверждённая сборка ESDS 0.9.17.  
**Целевая сборка:** 0.9.18.  
**Область работ:** только плагин, семантический реестр, универсальная инструкция и документация. Палитры не разрабатывать и не менять.

## 1. Цели
1. Завершить разделение иностранных слов/выражений и отдельных иностранных букв/коротких буквосочетаний.
2. Сделать новый класс доступным в CSS, встроенном справочнике, копируемом списке классов, инструкции ИИ и демонстрационном предпросмотре.
3. Зафиксировать требование к будущему оформлению таблиц: смысловые колонки могут иметь различающиеся фон, цвет текста, заголовки и акценты.
4. Сохранить совместимость и пользовательские данные.

## 2. Семантический класс
- `st-fo` — иностранное слово или выражение любой письменности/языка.
- `st-lt` — отдельная иностранная буква или короткое сочетание из 2–3 букв (например, `ñ`, `th`, `sch`).
- `st-lt` имеет собственное оформление: отдельный CSS-токен `--esds-letter` с безопасным fallback и пунктирное подчёркивание.
- `st-lt` не заменяет `st-fo`; оба класса остаются поддерживаемыми и семантически различными.

## 3. Таблицы — требование к дизайн-системе
Будущая палитра/дизайн-система должна уметь различать колонки таблицы по смысловой роли: фон и цвет текста колонок, оформление заголовков, аккуратные акценты. Контраст должен работать в светлом и тёмном режимах. Это правило относится к будущему дизайну палитр; в сборке 0.9.18 не добавляются новые палитры, не меняются существующие палитры, их JSON-схемы, значения или визуальные пресеты.

## 4. Ограничения
- Не менять пользовательский `data.json` и структуру библиотеки.
- Не менять палитры, фоновые наборы, блок-стили, их данные или импорт/экспорт.
- Не менять содержание заметок, Properties или frontmatter.
- Не добавлять сетевые запросы, зависимости или фоновые задачи.
- Не изменять GitHub-репозиторий.
- ZIP обновления не содержит `data.json`.

## 5. Критерии приёмки
- Версия manifest и versions.json — 0.9.18.
- `st-lt` присутствует в едином реестре; UI справочник и копирование классов строятся из этого реестра.
- Инструкция для ИИ ясно говорит: `st-fo` — слова/выражения, `st-lt` — одна буква/2–3 буквы.
- CSS для `st-lt` изолирован селекторами ESDS и имеет отдельное оформление.
- Табличное требование документировано как будущая возможность дизайн-системы, без изменения палитр в этой сборке.
- JS синтаксически проверен, JSON валиден, архив содержит нужные файлы и не содержит `data.json`.
- Реальный запуск на Android отмечается отдельно как требующий проверки на устройстве.
