# ESDS — 06 · Сочные и тропические

25 самостоятельных палитр ESDS, schemaVersion 4. Каждая содержит светлую и тёмную цветовые системы, отдельный токен `letter` для `st-lt`, 12 типов Callout с собственными цветами и рамками, общие стили таблиц и три индексированные колонки.

Импортируй нужные JSON-файлы через ESDS → Импорт палитры. Архив плагина не включает личный `data.json`.
