# Changelog — English Study Design Studio

## 0.9.22

### Импорт палитр
- Исправлена ошибка проверки ZIP-палитр: использовался несуществующий идентификатор `LEGACY_ROLE_KEYS` вместо актуального `ROLE_KEYS`.
- При отсутствии подходящих палитр теперь показываются конкретные причины отклонения JSON-файлов.
- ZIP-коллекция может содержать несколько палитр; импорт выполняется одной операцией с пропуском дубликатов и откатом библиотеки при ошибке.
- Для импорта палитр добавлен выбор нескольких JSON-файлов за один раз.

### Экспорт палитр
- Вместо ограничения одной категорией появился список палитр с индивидуальными флажками.
- Добавлены действия «Выбрать всё» и «Снять выбор».
- Все выбранные палитры экспортируются в один ZIP-файл; исходные категории сохраняются в данных палитр и манифесте коллекции.

### Совместимость
- Минимальная версия Obsidian остаётся 1.5.0.
- Формат палитр остаётся schemaVersion 4; существующие данные библиотеки не мигрируются и не перезаписываются.
