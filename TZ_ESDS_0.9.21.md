## 3. АНАЛИЗ ОКОН И КНОПОК (детальный)

### 3.1. DesignStudioModal (главное окно)

#### Верхняя панель быстрых действий
| Кнопка | Текущее поведение | Проблемы / Недостатки |
|--------|-------------------|-----------------------|
| ✦ Случайное сочетание | Генерирует случайную комбинацию | Нет визуальной обратной связи «что именно изменилось» |
| Последняя палитра / Создать палитру | Открывает builder или выбирает последнюю | Текст кнопки слишком длинный на узких экранах |
| ★ Избранное (N) | Переход в favorites | — |
| ☆ Избранные элементы (N) | Переход в itemFavorites | Дублирование концепции «избранного» запутывает |
| ◷ Недавние | Переход в recent | — |
| Библиотека | Переход в library | — |

#### Аккордеон «Общая палитра»
- Карточки палитр с цветовыми swatches
- Поиск + фильтр по категориям
- Сортировка
- Кнопки: Применить, Предпросмотр, Избранное, Копировать, Удалить (для user)

**Проблемы:**
- Нет индикатора «сейчас активна»
- При большом количестве палитр нет виртуализации / lazy-render
- Поиск работает только по названию, не по mood/description

#### Аккордеон «Фон заметки»
- Аналогично палитрам
- Есть возможность «переопределить» фон независимо от палитры

**Проблемы:**
- Неочевидно, когда фон «переопределён»
- Нет кнопки «Вернуть фон из палитры»

#### Нижний футер
| Кнопка | Поведение |
|--------|---------|
| ✓ Применить к заметке | Применяет выбранную комбинацию |
| ↺ Применить по умолчанию | Сбрасывает draft и применяет |
| Убрать оформление | Удаляет классы и маркеры из заметки |

**Проблемы:**
- Нет подтверждения перед «Убрать оформление»
- Нет горячих клавиш
- Нет индикации «есть несохранённые изменения в draft»

### 3.2. PreviewModal
- Показывает живой preview
- Кнопки: Применить, Закрыть, В избранное

**Проблемы:**
- Нет переключения light/dark
- Нет сравнения «до/после»

### 3.3. LibraryItemPreviewModal
- Хорошая навигация стрелками + свайп
- Переключение light/dark

**Проблемы:**
- На мобильных кнопки навигации могут быть мелкими

### 3.4. PaletteBuilderModal / BackgroundBuilderModal
- Полноценные редакторы

**Проблемы:**
- Нет live-preview при изменении цветов
- Нет валидации контраста (accessibility)
- Нет возможности импортировать цвета из изображения / CSS

### 3.5. CategoryManagerModal
- Управление категориями (rename, delete, reorder)

**Проблемы:**
- Нет drag-and-drop
- Удаление категории с элементами требует ручного перемещения

### 3.6. NoteBlockStyleModal
- Локальный стиль блоков для конкретной заметки

**Проблемы:**
- Сложный UI для новичков
- Нет пресетов «быстрого старта»

## 4. ВЫЯВЛЕННЫЕ ПРОБЛЕМЫ И ОШИБКИ

### 4.1. Функциональные / Логические
1. **Двойная концепция избранного** (favorites vs favoriteItems) — запутывает пользователя.
2. **Нет явного индикатора «текущее оформление заметки»** — пользователь не видит, что уже применено.
3. **При удалении категории** элементы остаются «бездомными».
4. **Поиск** работает только по имени, игнорирует description/mood/category.
5. **Отсутствует подтверждение** деструктивных действий (удалить оформление, удалить палитру).
6. **Нет undo** после применения / удаления оформления.
7. **На мобильных** некоторые кнопки имеют слишком длинный текст и обрезаются.
8. **Отсутствует SettingTab** — все настройки только внутри модалки.

### 4.2. UX / Дизайн
1. Слишком много одинаковых кнопок одного размера — слабая визуальная иерархия.
2. Аккордеоны при открытии нескольких секций создают очень длинный скролл.
3. Цветовые swatches иногда слишком мелкие.
4. Нет skeleton / loading состояний при применении.
5. Контраст некоторых кнопок в dark-теме может быть недостаточным.
6. Отсутствует keyboard navigation (Tab / Enter / Esc) в полной мере.
7. Нет tooltips на иконках.

### 4.3. Код / Производительность
1. `main.js` — монолит ~4600 строк. Сложно поддерживать.
2. Полный `render()` при любом изменении — дорого.
3. Нет debounce на поиске.
4. Большое количество inline event listeners.
5. CSS очень большой, много специфичности.
6. Отсутствует TypeScript / JSDoc в ключевых местах.

### 4.4. Недостающий функционал
| Функция | Приоритет |
|---------|-----------|
| SettingTab с глобальными настройками | Высокий |
| Горячие клавиши (Apply, Open Studio, Random) | Высокий |
| Подтверждение деструктивных действий | Высокий |
| Индикатор текущего оформления | Высокий |
| Улучшенный поиск (по mood, description, категории) | Средний |
| Drag-and-drop категорий и порядка | Средний |
| Live contrast checker в PaletteBuilder | Средний |
| Экспорт/импорт одной палитры (не только всей библиотеки) | Средний |
| «Сравнить с текущим» в Preview | Низкий |
| Виртуализация длинных списков | Низкий |
| История изменений (undo) | Низкий |

## 5. ТРЕБОВАНИЯ К ЦЕЛЕВОМУ СОСТОЯНИЮ (TO-BE)

### 5.1. Архитектура
- Разделить `main.js` логически на секции с чёткими комментариями-разделителями (или модули, если позволит bundler).
- Вынести константы, утилиты, рендереры в логические блоки.
- Добавить JSDoc к публичным методам.

### 5.2. UX-улучшения (обязательные)
1. **Индикатор текущего состояния** в шапке студии: «Сейчас на заметке: [Палитра] + [Фон]».
2. **Единое избранное** с табами «Комбинации» / «Элементы» (вместо двух отдельных кнопок).
3. **Подтверждение** перед удалением оформления и удалением пользовательских элементов.
4. **Debounced поиск** + поиск по mood/description.
5. **Визуальная иерархия кнопок**: Primary / Secondary / Danger / Quiet.
6. **Состояния кнопок**: loading, success, disabled.
7. **Улучшенная читаемость**: увеличить базовый размер шрифта в модалках, улучшить контраст.
8. **Мобильная адаптация**: более крупные touch-target’ы, сокращённые подписи.

### 5.3. Новые / улучшенные кнопки и элементы
| Место | Элемент | Описание |
|-------|---------|----------|
| Шапка студии | Badge «Текущее» | Показывает применённое оформление |
| Футер | Кнопка «Предпросмотр» | Открывает PreviewModal |
| Аккордеон фона | «Вернуть фон палитры» | Сбрасывает override |
| Библиотека | Фильтр + сортировка | Уже есть, улучшить |
| PaletteBuilder | Live preview + contrast | Показывать контраст текста |
| Все модалки | Esc закрывает | Стандартное поведение Obsidian |

### 5.4. Полный функционал по окнам (целевой)

#### DesignStudioModal
- Быстрые действия (Random, Favorites, Recent, Library)
- Аккордеоны: Палитра, Фон, (Advanced) Блоки, AI-инструкция, Справочник
- Живой preview справа или сверху (на широких экранах)
- Футер: Применить / По умолчанию / Убрать / Предпросмотр
- Индикатор текущего оформления

#### PreviewModal
- Light/Dark toggle
- Применить / В избранное / Закрыть

#### LibraryItemPreviewModal
- Навигация + свайп
- Light/Dark
- Применить / Избранное / Закрыть

#### Builders

- Валидация

#### CategoryManager

- Drag-and-drop (желательно)

### 5.5. Производительность
- Debounce поиска (250–300 ms)
- Избегать полного re-render там, где можно обновить только список
- Ограничить количество одновременно рендеримых карточек (пагинация / «Показать ещё»)

### 5.6. Доступность
- Достаточный контраст (WCAG AA где возможно)

## 8. РИСКИ
- Большой размер `main.js` — риск регрессий при глубоком рефакторинге.
- Мобильные устройства Obsidian имеют ограничения по производительности.
- Пользователи могут иметь кастомные палитры со старой структурой.

**Митигация:** изменения вводятся инкрементально, с сохранением обратной совместимости и тщательным тестированием `applySelected` / `removeDesign` / `ensureLibraryShape`.
